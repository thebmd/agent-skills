# 가격 판독기 (Price Decoder)

## 목적

**좋은 회사와 좋은 주식은 다르다.**

이 스킬은 적정주가를 계산하지 않는다. 대신 거꾸로 묻는다:

> **"지금 이 가격이 되려면, 이 회사가 앞으로 얼마나 벌어야 하지?"**

그리고 그 숫자를 **과거 실제 성적과 나란히 놓는다.** 판단은 사용자가 한다.

## 왜 역DCF인가 (사용자에게 설명할 때 이 비유를 쓴다)

일반 DCF는 성장률을 **내가 넣어야** 한다. 초보에겐 불가능하고, 가정이 틀리면 결과가 전부 틀린다.

역DCF는 반대다. **가정을 시장이 대신 넣어줬고, 우리는 그게 말이 되는지만 보면 된다.**

> 중고차에 5천만원이 붙어 있으면 "이게 5천만원짜리 성능이 나오나?" 묻지, 성능을 먼저 정하고 가격을 계산하지 않는다.

## 절대 규칙

1. **적정주가를 제시하지 않는다.** 이 스킬은 "얼마다"라고 말하지 않는다. "시장이 뭘 기대하는지"만 말한다.
2. **모든 계산은 코드 실행으로.** 암산·추정 금지.
3. **입력값의 출처를 전부 명시한다.** 어디서 가져온 숫자인지 모르면 쓰지 않는다.
4. **결론을 먼저, 계산은 접어둔다.** 초보가 이해해야 한다. 계산 과정은 아래쪽 접이식으로.
5. **출력은 한국어.**
6. **반드시 경고를 단다**: 이 숫자는 판단의 시작이지 답이 아니다.

## 필요한 입력값 (딱 5개)

역DCF는 외부 시계열 데이터가 필요 없다. **이 5개면 계산된다.**

| 값 | 어디서 | 비고 |
|---|---|---|
| **현재 주가** | 웹검색 또는 사용자 입력 | 조회 시각 명시 |
| **발행주식수** | 최근 10-K/10-Q 또는 사업보고서 | 희석 주식수(Diluted) 사용 |
| **최근 FCF** | 현금흐름표 | 영업활동현금흐름 − CapEx |
| **순부채** | 재무상태표 | 총부채 − 현금성자산 |
| **할인율(WACC)** | 기본 9~10% | 아래 규칙 참조 |

### 값을 못 구할 때

**절대 추정하지 않는다.** 사용자에게 묻는다:
```
발행주식수를 확인할 수 없습니다. 다음 중 하나를 해주세요:
1) 최근 10-K/사업보고서 업로드
2) 숫자 직접 입력
```

### FCF 정규화 ⚠️ (중요)

**최근 1년 FCF가 비정상이면 결과가 통째로 왜곡된다.** 반드시 체크한다:

- 최근 3년 FCF를 나란히 본다
- 최근값이 3년 평균 대비 ±40% 이상 벗어나면 → **3년 평균을 쓰고, 카드에 명시한다**
- 일회성 요인(대규모 소송 합의금, 자산 매각, 팬데믹)이 있으면 → 사용자에게 알리고 선택하게 한다
- FCF가 음수면 → **역DCF 불가.** 솔직히 말한다: "이 기업은 현재 잉여현금흐름이 마이너스라 역DCF가 의미 없습니다. 흑자 전환 시점을 먼저 봐야 합니다."

### 할인율 기본값

| 유형 | WACC |
|---|---|
| 대형 안정 기업 (S&P500 대형주) | 9% |
| 일반 | 10% |
| 고성장·고변동 | 12% |
| 한국 중소형 | 11~12% |

**할인율은 반드시 민감도 분석에 포함한다** (아래 참조). 하나의 값에 의존하지 않는다.

## 계산 방법

### 모델 구조 (2단계 성장)

```
1단계: 향후 10년 — 성장률 g (이걸 역산한다)
2단계: 영구성장 — 2.5% 고정 (장기 GDP 성장률 수준)
```

### 역산 로직

```python
# 목표: 아래 식을 만족하는 g를 찾는다
#
# 시가총액 = Σ(t=1~10) [FCF × (1+g)^t / (1+WACC)^t]
#           + [FCF × (1+g)^10 × (1+0.025) / (WACC - 0.025)] / (1+WACC)^10
#           - 순부채
#
# 이분법(bisection)으로 g를 찾는다
```

**반드시 코드 실행으로 계산한다.** 이분법 또는 scipy 최적화 사용.

### 민감도 분석 (필수)

g 하나만 내놓지 않는다. **할인율을 흔들어본다:**

| WACC | 요구 성장률 |
|---|---|
| 8% | ...% |
| 10% (기본) | ...% |
| 12% | ...% |

이걸 보여줘야 사용자가 "이 숫자가 얼마나 흔들리는지" 안다.

### 과거 실적 (비교 대상 · 이게 없으면 무의미)

역산한 g를 **혼자 두면 아무 의미가 없다.** 반드시 과거와 나란히 놓는다:

- 지난 **5년 FCF 연평균성장률(CAGR)**
- 지난 **5년 매출 CAGR**
- 지난 **10년 FCF CAGR** (가능하면)

**이 비교가 이 스킬의 결론이다.**

## 출력 구성 (아티팩트)

### ① 결론 — 딱 두 문장 (최상단, 가장 크게)

```
지금 디즈니 주가는 앞으로 10년간 매년 X%의 현금흐름 성장을 가정하고 있습니다.

지난 5년 실제 성장률은 Y%였습니다.
```

**이 두 문장이 전부다.** 초보는 이것만 읽고 판단할 수 있어야 한다.

### ② 판정 한 줄

X와 Y를 비교해서 한 줄:

| 조건 | 판정 문구 |
|---|---|
| X < Y × 0.7 | 🟢 시장의 기대가 과거 실적보다 **낮습니다.** 시장이 뭘 걱정하는지 찾아봐야 합니다. |
| X ≈ Y (±30%) | 🟡 시장은 이 회사가 **과거 수준을 유지**할 거라 보고 있습니다. |
| X > Y × 1.5 | 🔴 시장은 이 회사가 과거보다 **훨씬 잘할 거라** 기대하고 있습니다. 그 근거가 있는지 확인해야 합니다. |

⚠️ 판정은 "사라/팔아라"가 아니다. **"어디를 더 파봐야 하는지"**를 알려주는 것이다. 이 점을 카드에 명시한다.

### ③ 그래프 (1장이면 충분)

**요구 성장률 vs 과거 실제 성장률** 막대 그래프.
- 막대 3~4개: 시장 요구(X) / 5년 실제 / 10년 실제 / (있으면) 애널리스트 컨센서스
- 한눈에 높낮이가 보여야 한다

### ④ 민감도 표

WACC 8/10/12%별 요구 성장률.

### ⑤ 이 숫자가 흔들리는 조건 (2~3줄)

> "만약 FCF가 3년 평균이 아니라 최근 1년 기준이면, 요구 성장률은 X'%로 바뀝니다."
> "할인율을 12%로 보면 X''%가 필요합니다."

### ⑥ 계산 과정 (접이식 · 덕후용)

`<details>` 태그로 접어둔다:
- 사용한 입력값 5개 + 각각의 출처
- FCF 정규화 여부와 이유
- 모델 가정 (10년 + 영구성장 2.5%)
- 계산 코드/식

### ⑦ ⚠️ 경고 (반드시 · 생략 금지)

```
이 숫자는 판단의 시작이지 답이 아닙니다.

- 가정(할인율, 성장 기간, 영구성장률)이 바뀌면 결과가 바뀝니다.
- 역DCF는 "시장이 뭘 기대하는가"를 보여줄 뿐, "얼마가 적정한가"를 말하지 않습니다.
- 그 기대가 타당한지는 사업 모델과 경쟁 환경을 직접 확인해야 알 수 있습니다.
- 투자 판단과 그 결과는 본인 책임입니다.
```

## 한국 주식

가능하다. 다만 조정할 것:

| 항목 | 조정 |
|---|---|
| 자료 출처 | DART 사업보고서 (연결재무제표 기준) |
| 통화 | 원화 그대로. 환산하지 않는다 |
| 할인율 | 대형주 10%, 중소형 11~12% |
| 영구성장률 | 2.0% (한국 장기 성장률 감안) |
| 주의 | 지배주주 순이익 기준 확인. 비지배지분 큰 기업은 카드에 표시 |

```
web_search: "{TICKER} stock price"                    (현재 주가)

web_search: "{TICKER} shares outstanding diluted"

```
한국: `{기업명} DART 사업보고서 현금흐름표`

- **업로드 자료가 있으면 그게 1순위.** 웹검색은 주가만.
- 각 값의 출처를 기록한다

### Step 2 — 검증 (계산 전에)

- FCF 음수인가? → 중단하고 안내
- 최근 FCF가 3년 평균 대비 ±40% 벗어나나? → 정규화
- 값 중 하나라도 출처 불명? → 사용자에게 질문

### Step 3 — 계산 (코드 실행)

- 역DCF 이분법으로 g 역산
- WACC 8/10/12% 민감도
- 과거 5년/10년 CAGR 계산

### Step 4 — 아티팩트 생성

①~⑦ 순서 그대로.

**결론 두 문장이 가장 크고 가장 위에.** 이걸 어기면 초보가 이해 못 한다.

### Step 5 — 마무리 한 줄

- 판정 한 줄 반복

## 자주 하는 실수 (하지 말 것)

| 실수 | 왜 안 되나 |
|---|---|
| 적정주가를 제시 | 이 스킬의 목적과 정반대 |
| 요구 성장률만 보여주고 과거와 비교 안 함 | 비교가 없으면 숫자에 의미가 없다 |
| 계산 과정을 위에 길게 노출 | 초보가 이탈한다. 접어둔다 |
| FCF 이상치를 그냥 사용 | 결과 전체가 왜곡 |
| 민감도 없이 단일값 제시 | 정밀해 보이지만 거짓이다 |
| 경고 문구 생략 | 절대 금지 |
| "사라/팔아라" 판정 | 이건 조사 방향 제시지 매매 신호가 아니다 |
| 값을 추정해서 채워넣음 | 모르면 묻는다 |
